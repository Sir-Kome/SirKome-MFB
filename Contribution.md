# Contribution Guidelines

## Branches

- Never push directly to production.
- Create feature branches from development.
- Open a Pull Request to development.

## Pull Requests

- Development requires one reviewer.
- Staging requires two reviewers.
- Production merges are done by the repository owner.

## Code Quality

Every Pull Request must pass:

- Unit Tests
- Integration Tests
- Security Checks
- Linting
- Coverage
